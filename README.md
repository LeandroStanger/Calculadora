Uma calculadora web funcional com interface limpa e intuitiva, capaz de realizar operações matemáticas básicas.

## 📝 Descrição

O projeto **Calculadora** é uma aplicação web que simula uma calculadora tradicional, permitindo ao usuário realizar operações aritméticas como adição, subtração, multiplicação, divisão e porcentagem. Desenvolvida com foco em simplicidade e usabilidade, é ideal para uso diário, estudos de lógica de programação ou como base para projetos mais complexos.

## ⚙️ Funcionalidades

Com base na interface disponível, as funcionalidades implementadas são:

- **Operações básicas**: adição (`+`), subtração (`-`), multiplicação (`×`) e divisão (`÷`).
- **Porcentagem** (`%`): cálculo percentual sobre o valor atual.
- **Limpeza** (`C`): limpa completamente o visor e reinicia a operação.
- **Apagar último caractere** (`⌫`): remove o último dígito ou operador digitado.
- **Entrada de números e ponto decimal**: suporte para números com casas decimais.
- **Cálculo em tempo real**: exibe o resultado ao pressionar o botão de igual (`=`).
- **Design responsivo**: interface que se adapta a diferentes tamanhos de tela.

## 🔧 Como Executar o Projeto

### Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Edge, Safari)

### Passo a Passo

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/LeandroStanger/Calculadora.git
   cd Calculadora
   ```

2. **Abra o arquivo `index.html`** diretamente no navegador:
   - Dê um duplo clique no arquivo
   - Ou arraste-o para uma janela do navegador

3. **Utilize a calculadora**:
   - Clique nos botões numéricos e operadores
   - Pressione `=` para obter o resultado
   - Use `C` para limpar ou `⌫` para corrigir

## 🎯 Exemplo de Uso

| Sequência de Cliques | Resultado Esperado |
|---------------------|-------------------|
| `7` `×` `8` `=` | `56` |
| `1` `0` `0` `%` | `1` (100% de 1) |
| `5` `0` `–` `2` `0` `=` | `30` |
| `⌫` (após digitar erro) | Remove o último caractere |
